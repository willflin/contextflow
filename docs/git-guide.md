# Git 使用建议 / Git Guide

## 现在是否必须初始化 Git？ / Is Git Required Now?

建议初始化，但不强制。

Recommended, but not mandatory.

Git 的作用是保存阶段性成果，方便回退和面试展示开发过程。

Git keeps project milestones, supports rollback, and helps show the development process in interviews.

## 建议提交节奏 / Suggested Commit Rhythm

- Phase 0：前后端基础框架 / frontend-backend foundation
- Phase 0.5：项目规范和结构 / project structure and conventions
- Phase 1：认证与权限 / auth and authorization
- Phase 2：数据库核心 / database core

## 提交信息格式 / Commit Message Style

```text
phase0: initialize frontend and backend skeleton
phase0.5: add project conventions and module boundaries
```
